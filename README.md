# UC Berkeley CS61B (Spring 2018)

> 此仓库记录本人在大四寒假期间，历时两月独立完成的 UC Berkeley CS61B 全套项目与作业代码（Autograde 全通过）。从数学专业跨界到计算机，得 Josh Hug 启蒙，初窥程序设计之美与面向对象之智，亦淬出“分层与抽象”的系统思维。然余质性愚钝，虽勉力为之，于代码构筑之玄妙、系统封装之大智，终觉雾里看花，未能顿悟。盖见巍峨之高山，方知己身之渺小；识造物之伟大，深觉所欠尚多。

## 🛠️ Projects

| 名称 | 算法与内容简介 |
| :--- | :--- |
| **proj0: NBody** | **天体物理引力模拟**<br>基于牛顿万有引力定律模拟多天体运行。按时间步长迭代计算天体所受合力与瞬时加速度，利用 `StdDraw` 结合双缓冲技术实现星体公转动画与音乐同步播放。 |
| **proj1a: Data Structures** | **双端队列实现**<br>手工构建 `Deque` 基础容器：`LinkedListDeque` 采用带圆形哨兵节点的双向循环链表，保证头尾增删均为 $\mathcal{O}(1)$；`ArrayDeque` 采用环形数组处理索引取模，并在低负载率（$< 25\%$）时自动减半缩容。 |
| **proj1b: Applying Deque** | **接口抽象与回文判定**<br>提取 `Deque<T>` 泛型接口；基于自定义字符判定器（`CharacterComparator`）与双端队列，实现普通回文串以及允许偏移量为 $N$ 的广义回文词（Off-By-N）检测算法。 |
| **proj1gold: Testing** | **自动化黑盒对拍测试**<br>编写随机测试（Randomized Testing）。生成随机操作调用序列，实时对标官方标准实现的返回状态，在复杂调用场景下自动追踪并输出定位 Bug 的最小调用链。 |
| **proj2: BYOW** | **2D 随机迷宫世界生成与探索**<br>• **Phase 1**：基于伪随机数种子（PRNG）程序化生成互不重叠的矩形房间，以 L/Z 型走廊连通构建全局连通图；<br>• **Phase 2**：加入交互引擎，支持键盘控制角色移动、HUD 瓦片信息悬停检测与游戏状态序列化读写存档。 |
| **proj3: Bear Maps** | **仿 Google 地图 Web 系统**<br>• **Rasterer**：计算屏幕经度像素分辨率（LonDPP），自适应匹配四叉树层级并拼接可视区瓦片图片；<br>• **GraphDB**：基于 SAX 流式解析 OpenStreetMap XML 地图数据并构建路网拓扑；<br>• **Router**：实现 A* 最短路径寻路算法（采用大圆距离启发函数），并生成分步导航指引；<br>• **Autocomplete**：利用前缀树（Trie）实现地名搜索前缀实时自动补全与模糊匹配。 |

## 📚 Homeworks

| 名称 | 算法与内容简介 |
| :--- | :--- |
| **hw1: Guitar Hero** | **环形队列与物理声音合成**<br>基于 Karplus-Strong 算法模拟拨弦物理震动。利用环形缓冲区（`ArrayRingBuffer`）进行能量衰减与白噪声反馈更新，实现实时键盘交互模拟吉他发声。 |
| **hw2: Percolation** | **渗流模型与并查集优化**<br>利用蒙特卡洛方法模拟多孔介质的渗流相变阈值。使用加权并查集（`WeightedQuickUnionUF`）跟踪连通性，并通过双并查集建模巧妙消除了“渗流倒灌（Backwash）”问题。 |
| **hw3: Hashing** | **散列分布与等价契约**<br>深入分析 Java 集合框架底层原理，测试哈希冲突与桶分布特征，严格遵循不可变对象设计并正确实现 `equals` 与 `hashCode` 契约规范。 |
| **hw4: 8-Puzzle** | **A\* 启发式搜索求解滑块拼图**<br>将八数码滑块游戏建模为状态图搜索问题。利用优先队列（`MinPQ`）与曼哈顿距离（Manhattan Distance）作为可采纳启发函数，搜寻步数最少的最优还原路径。 |
| **hw5: Seam Carving** | **内容感知图像缩放（缝隙裁剪）**<br>基于双能量梯度函数计算每个像素的重要性，利用动态规划在 DAG 图中求解一条自顶向下的最小能量缝隙（Seam）并将其移除，实现无失真智能缩放。 |
| **hw6: Boggle** | **Trie 树与网格 DFS 回溯**<br>结合字典树（Trie）与二维矩阵深度优先搜索（DFS）回溯，在 $N \times M$ 棋盘中进行前缀剪枝，高效率检索棋盘中蕴含的所有有效英语单词。 |
| **hw7: Huffman Coding** | **霍夫曼编码与无损数据压缩**<br>统计字节词频构建最优二叉前缀树（Huffman Tree），利用可变长前缀码与位流（`BitSequence`）实现文本文件的端到端压缩与无损还原。 |

## 🧪 Labs
